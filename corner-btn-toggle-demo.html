corner-btn 切換顯示 / 隱藏

v2 新增 target 屬性：點擊角落按鈕，切換任意 div 的顯示狀態。

範例 1

最基本：點擊右上角切換下方面板

在 <corner-btn> 加上 target="#panel-id" 即可。 面板初始為隱藏（display:none），點擊後顯示，再點收起。

點擊右上角三角形

這是觸發容器，角落按鈕在右上方。

這個面板一開始是隱藏的（display:none）。

點擊右上角按鈕後出現；再點一次收回去。

按鈕與面板可以放在頁面任意位置，只要 target 的選擇器對應到正確 ID 即可。

<div class="card">
  <corner-btn
    corner="top-right"
    color="#C8DD5A"
    size="36"
    target="#panel-basic"
    title="展開 / 收起"
  ></corner-btn>
  標題列...
</div>

<!-- 面板可在頁面任意位置 -->
<div id="panel-basic" style="display:none">
  面板內容...
</div>
範例 2

active-color — 開關狀態用不同色彩指示

color 是關閉時的顏色，active-color 是面板開啟時的顏色。 三角形色彩會隨狀態自動切換（含 CSS transition 淡變）。
此範例面板初始為顯示，所以按鈕初始用 active-color。

左上角：綠色=開啟，藍灰=關閉

面板目前是顯示的，按鈕為綠色（active-color）。點擊收起後變藍灰色。

這個面板初始是顯示的，所以按鈕顯示 active-color（綠色）。

點擊後隱藏，按鈕切換為 color（藍灰色）。

<corner-btn
  corner="top-left"
  color="#95BDD7"        // 關閉狀態
  active-color="#40C99A"  // 開啟狀態
  target="#panel-active"
></corner-btn>

<!-- 面板初始顯示（無 display:none） -->
<div id="panel-active">...</div>
範例 3

animate="fade" — 淡入淡出動畫

加上 animate="fade" 屬性，顯示 / 隱藏時有 0.25s 淡入淡出效果。

右上角 — 含 fade 動畫

點擊後面板以淡入淡出的方式切換。

這個面板使用 animate="fade"，顯示與隱藏都有淡入淡出效果。

動畫期間不會響應重複點擊（transitionend 後才清除 display）。

<corner-btn
  corner="top-right"
  color="#7B6CF0"
  active-color="#C3A5E5"
  target="#panel-fade"
  animate="fade"
></corner-btn>
範例 4

一個按鈕控制多個目標（逗號分隔選擇器）

target 支援逗號分隔多個 CSS 選擇器，一次切換多個元素。 同一個 class 也可以當作群組選擇器使用。

右下角 — 同時控制下方兩個面板

點擊右下角，下方兩個面板同時顯示或隱藏。

面板 A：這是第一個被控制的目標。

面板 B：這是第二個被控制的目標，與面板 A 同步切換。

<corner-btn
  corner="bottom-right"
  target="#multi-a, #multi-b"
></corner-btn>

<!-- 也可以用 class 做群組 -->
<corner-btn target=".my-group"></corner-btn>
範例 5

toggle-mode="class" — 由 CSS 控制動畫

設定 toggle-mode="class" 後，元件只加 / 移除 class， 不直接操作 display，讓你完全用 CSS 控制顯示邏輯與動畫（slide、flip 等）。 toggle-class 指定要切換的 class 名稱（預設 is-hidden）。

class 模式 — CSS slide 動畫

元件只切換 is-hidden class，動畫完全由 CSS transition 控制。

這個面板使用 max-height transition 達成 slide 效果。

元件本身不干預動畫，只負責加 / 移除 .is-hidden。

/* CSS：自訂 slide 動畫 */
#panel-cls {
  max-height : 200px;
  overflow   : hidden;
  transition : max-height .35s ease, opacity .3s ease;
  opacity    : 1;
}
#panel-cls.is-hidden {
  max-height : 0;
  opacity    : 0;
}

<!-- HTML：使用 class 模式 -->
<corner-btn
  target="#panel-cls"
  toggle-mode="class"
  toggle-class="is-hidden"
></corner-btn>
範例 6

toggle 事件 + JS API：open() / close()

每次切換後發出 toggle 事件（detail.open 反映最新狀態）。 也可直接呼叫 .open() / .close() 強制設定狀態。

右上角 — toggle 事件 demo

點擊後在下方 log 中觀察事件 detail。

這個面板的開關狀態被 toggle 事件追蹤。

toggle 事件 log： 
// 監聽 toggle 事件
document.querySelector('#cb-event')
  .addEventListener('toggle', e => {
    const { open, corner, action } = e.detail;
    console.log(open ? '已顯示' : '已隱藏');
  });

// 強制開啟 / 關閉
document.querySelector('corner-btn[action="event-demo"]').open();
document.querySelector('corner-btn[action="event-demo"]').close();
參考

v2 新增屬性速查

屬性預設值說明
target— CSS 選擇器，可逗號分隔多個目標；點擊後切換這些元素的顯示狀態
toggle-modedisplay display：操作 style.display ／ class：切換指定 class
toggle-classis-hidden class 模式使用的 CSS class 名稱
animate— fade：display 模式淡入淡出 0.25s；class 模式動畫由 CSS 自理
active-color— 目標顯示（開啟）時的三角形色彩；未設則不變色
toggle 事件 detail 結構：
{
  open   : true,              // 切換後目標是否顯示
  corner : "top-right",       // 觸發按鈕的角落
  action : "my-action",       // action 屬性值
  targets: [HTMLElement, ...]  // 被切換的元素陣列
}
