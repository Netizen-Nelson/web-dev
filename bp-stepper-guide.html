bp-stepper 使用說明

多步驟進度條元件 — 程式碼與預覽對照

元素結構 步驟狀態 佈局方向 連接器 連接器標籤 自動編號 Progress 模式 Progress-show 模式 按鈕自訂 Clickable 模式 換行 U-turn 填滿容器 尺寸微調 自訂顏色 JavaScript API 事件 全域預設

§1 元素結構

bp-stepper 由三層自訂元素組成：<bp-stepper>（容器）、 <bp-step>（每個步驟）、<bp-step-title> 與 <bp-step-content>（選用的標題與內文子元素）。 引入 bp-stepper.js 後不需任何 new 或 init()， 頁面載入後自動初始化所有 <bp-stepper>。

HTML
<!-- 引入元件 -->
<script src="bp-stepper.js"></script>

<bp-stepper data-theme="sky">

  <bp-step>
    <bp-step-title>步驟標題</bp-step-title>
    <bp-step-content>
      步驟說明文字
    </bp-step-content>
  </bp-step>

  <bp-step>...</bp-step>
  <bp-step>...</bp-step>

</bp-stepper>
預覽
下載素材 從官方網站取得最新版本 設定環境 編輯 config 填入必要參數 啟動服務 執行並確認正常運行
標題和內文均為選用。只寫 <bp-step> 不含子元素也完全有效， 適合純狀態指示用途。

§2 步驟狀態（data-state）

每個 <bp-step> 可設定 data-state 屬性，控制卡片背景色、連接線顏色與 badge 符號。 未設定時為「待完成」狀態（灰白）。

值意義Badge外觀
（不設定）待完成數字預設色調
active進行中（當前步驟）數字高亮色調＋卡片特殊背景
done已完成✓完成色調
error發生錯誤!警告色調
HTML
<bp-stepper data-theme="teal">

  <!-- 已完成 -->
  <bp-step data-state="done">
    <bp-step-title>已完成</bp-step-title>
  </bp-step>

  <!-- 進行中 -->
  <bp-step data-state="active">
    <bp-step-title>進行中</bp-step-title>
  </bp-step>

  <!-- 發生錯誤 -->
  <bp-step data-state="error">
    <bp-step-title>錯誤</bp-step-title>
  </bp-step>

  <!-- 待完成（不設定）-->
  <bp-step>
    <bp-step-title>待完成</bp-step-title>

§3 佈局方向（data-layout）

預設水平排列。加上 data-layout="vertical" 切換為垂直堆疊， 連接線與箭頭自動改為由上往下。垂直模式下，data-card-width 的語義為最小寬度， 卡片會自動填滿父容器。

<bp-stepper data-theme="ocean">
  <bp-step data-state="done">
    <bp-step-title>Step 1</bp-step-title>
  </bp-step>
  <bp-step data-state="active">
    <bp-step-title>Step 2</bp-step-title>
  </bp-step>
  <bp-step>
    <bp-step-title>Step 3</bp-step-title>
  </bp-step>
</bp-stepper>
垂直

  data-layout="vertical"
  data-theme="ocean"
  data-card-width="300px">

       300px 為最小寬度 -->
  ...
</bp-stepper>

§4 連接器樣式（data-connector-style）

控制步驟之間連接線的線條類型。支援三種值：solid（實線，預設）、 dashed（虛線）、dotted（點線）。 所有模式均搭配箭頭，且 z-index 已調整為正確覆蓋在卡片上方。

HTML
<!-- 實線（預設，可省略）-->
<bp-stepper
  data-connector-style="solid"
  data-theme="lavender">
  ...
</bp-stepper>

<!-- 虛線 -->
<bp-stepper
  data-connector-style="dashed"
  data-theme="yellow">
  ...
</bp-stepper>

<!-- 點線 -->
<bp-stepper
  data-connector-style="dotted"
  data-theme="indigo">
  ...
</bp-stepper>

§5 連接器標籤（data-connector-label）

<bp-stepper
  data-theme="sky"
  data-connector-label="→ 下一步">

§7 Progress 模式（data-mode="progress"）

設定 data-mode="progress" 後，每個步驟右下角自動注入推進按鈕。 點擊後將前一步驟標為 done，並啟動下一步。最後一步點擊後觸發 bps:complete 事件， 所有步驟全部標為 done。

<bp-stepper
  data-mode="progress"
  data-theme="teal">

  <bp-step data-state="active">
    <bp-step-title>建立帳號</bp-step-title>
    <bp-step-content>
      填寫姓名與電子郵件
    </bp-step-content>
  </bp-step>

  <bp-step>
    <bp-step-title>驗證信箱</bp-step-title>
    <bp-step-content>
      輸入收到的 6 位數驗證碼
    </bp-step-content>
  </bp-step>

  <bp-step>
    <bp-step-title>完成設定</bp-step-title>
    <bp-step-content>
      選擇偏好與頭像
    </bp-step-content>
  </bp-step>

</bp-stepper>
右下角的 › 即推進按鈕（預設圖示），點擊後前進一步。

§8 Progress-show 模式（data-mode="progress-show"）

在 progress 基礎上增加「逐步揭示」功能：初始化時只顯示第一個步驟，點擊推進後才動畫展開下一步。 適合引導式表單或教學流程，避免使用者看到所有步驟而分心。

  data-theme="indigo"

§10 Clickable 模式（data-clickable="true"）

設定後，每個步驟卡片本身可以被點擊（支援鍵盤 Enter / Space）。 點擊哪張卡片，就直接跳到該步驟，前面的步驟全部標為 done。 適合可自由跳轉的分頁或向導型介面。

HTML
<bp-stepper
  data-clickable="true"
  data-theme="pink">

  <bp-step data-state="done">
    <bp-step-title>概覽</bp-step-title>
  </bp-step>

  <bp-step data-state="active">
    <bp-step-title>功能一</bp-step-title>
  </bp-step>

  <bp-step>
    <bp-step-title>功能二</bp-step-title>
  </bp-step>

  <bp-step>
    <bp-step-title>進階設定</bp-step-title>
  </bp-step>

</bp-stepper>
可與 progress 模式同時使用：按鈕點擊依序推進，卡片點擊任意跳轉。

§11 換行 U-turn（data-wrap）

步驟數量較多時，設定 data-wrap="N" 讓前 N 個步驟排在第一行， 其餘步驟反向排在第二行，並自動插入 U 型轉角連接器。 適合在固定寬度容器內展示大量步驟的流程。

HTML
<bp-stepper
  data-wrap="4"
  data-theme="focus"
  data-card-width="160px"
  data-gap="36px">

  <bp-step data-state="done"><bp-step-title>需求分析</bp-step-title></bp-step>
  <bp-step data-state="done"><bp-step-title>系統設計</bp-step-title></bp-step>
  <bp-step data-state="done"><bp-step-title>開發</bp-step-title></bp-step>
  <bp-step data-state="active"><bp-step-title>測試</bp-step-title></bp-step>

  <!-- 第二行（反向排列）-->
  <bp-step><bp-step-title>驗收</bp-step-title></bp-step>
  <bp-step><bp-step-title>上線</bp-step-title></bp-step>
  <bp-step><bp-step-title>維護</bp-step-title></bp-step>

</bp-stepper>

§15 JavaScript API

所有函式透過 window.BPStepper 存取，第一個參數均為目標 <bp-stepper> 的 DOM 元素。

函式參數說明
BPStepper.setActive(el, index)el：stepper 元素
index：步驟索引（0起）		跳到指定步驟，前面全標 done。index ≥ 步驟數時全部完成並觸發 bps:complete。
BPStepper.setError(el, index)同上將指定步驟標為 error 狀態，badge 改為 !。
BPStepper.resetStates(el)el清除所有步驟狀態，回到初始全灰。progress-show 模式下同時重新隱藏後續步驟。
BPStepper.progressShowNext(el, fromIndex)el
fromIndex：當前步驟索引		先以動畫揭示下一步，再推進 active 狀態。通常由推進按鈕內部呼叫。
BPStepper.init(root?)root（選用）：搜尋根節點手動初始化。在 DOM 尚未存在就執行的情況下，動態插入 bp-stepper 後呼叫此函式。
JavaScript
// 取得目標 bp-stepper 元素
const el = document.getElementById('my-stepper');

// 跳到第 2 步（index = 1）
BPStepper.setActive(el, 1);

// 將第 3 步標為錯誤
BPStepper.setError(el, 2);

// 重置所有狀態
BPStepper.resetStates(el);

// 全部完成（index 超過步驟數）
BPStepper.setActive(el, 999);

// 動態插入後初始化
const newStepper = document.createElement('bp-stepper');
// ...（設定屬性與子元素）
document.body.appendChild(newStepper);
BPStepper.init();  // 掃描全頁重新初始化
// 或只初始化特定容器：
BPStepper.init(document.getElementById('container'));

§16 事件（bps:change / bps:complete）

步驟切換時，<bp-stepper> 元素會向上冒泡發出自訂事件， 可在父元素監聽以執行業務邏輯（例如送出 AJAX、更新 URL）。

事件名稱觸發時機event.detail
bps:change任一步驟切換（包含 setActive、點擊、按鈕推進）{ index, prevIndex, el }
bps:complete所有步驟全部標為 done{ el }
JavaScript
const el = document.getElementById('my-stepper');

// bps:change — 步驟切換
el.addEventListener('bps:change', e => {
  const { index, prevIndex } = e.detail;
  console.log(`從 Step ${prevIndex} 切換到 Step ${index}`);
  // 可在此更新側邊內容、送 AJAX 等
});

// bps:complete — 所有步驟完成
el.addEventListener('bps:complete', () => {
  console.log('所有步驟已完成！');
  // 跳轉頁面、顯示成功彈窗等
});

// 也可監聽在父元素（bubbles: true）
document.addEventListener('bps:change', e => {
  const whichStepper = e.detail.el;
  // e.detail.el 是發出事件的 bp-stepper
});

§17 全域預設覆寫（BPStepper.defaults）

修改 BPStepper.defaults 物件中的屬性，可統一改變頁面上所有後續初始化的 <bp-stepper> 預設值。必須在 bp-stepper.js 載入後、 HTML 解析（或 DOMContentLoaded）之前設定，才能對靜態 HTML 中的元件生效。 若要在 DOMContentLoaded 後修改，對動態插入的 stepper 仍有效。

JavaScript
// 在 bp-stepper.js 引入後立即執行
const d = BPStepper.defaults;

// 全域改變預設主色
d.color       = '#0ABDC6';
d.colorActive = '#DECA4B';
d.colorDone   = '#20C21D';
d.titleColor  = '#0ABDC6';

// 改變預設卡片寬度
d.cardWidth   = '260px';

// 改變預設連接器
d.connectorStyle = 'dashed';

// 關閉全域自動編號
d.autoNumber  = false;

// 全域設定預設主題
d.theme       = 'ocean';
// 此後所有未設定 data-theme 的 stepper
// 都會使用 ocean 主題

// 可用屬性完整清單（與 data-* 屬性對應）：
// color, colorActive, colorDone, colorError
// textColor, titleColor, badgeBg
// cardBg, cardBgActive, cardBgDone, cardBgError
// stroke, radius, cardWidth, cardPadding
// gap, badgeSize, fontSize, titleSize
// badgeFontSize, connectorStyle, arrowSize
// padTop, padBottom, padX
// autoNumber, theme
// progressIcon, progressText
// progressDoneIcon, progressDoneText
// progBtnSize
說明
BPStepper.defaults 是一個普通 JS 物件，直接修改屬性即可。 個別 stepper 的 data-* 屬性和 data-theme 優先順序高於全域預設。
優先順序（由高至低）：
1. 個別 bp-step 的 data-*（按鈕自訂）
2. bp-stepper 的 data-* 屬性
3. data-theme 主題設定
4. BPStepper.defaults 全域預設
