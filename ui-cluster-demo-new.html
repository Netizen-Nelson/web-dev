ui-cluster.js — 新屬性說明

label-gap & label-width：精確控制圓形到標籤的距離與標籤寬度

新增屬性總覽

屬性套用對象型別預設值說明
label-gap <ui-cluster> CSS 長度 4px 主圓與其下方標籤的距離（margin-top）。
label-width <ui-cluster> CSS 長度 90px 主圓標籤的最大寬度（max-width）。
node-label-gap <ui-cluster> CSS 長度 6px 所有子圓與其標籤距離的全域預設值，可被個別 <cluster-node> 的 label-gap 覆蓋。
node-label-width <ui-cluster> CSS 長度 76px 所有子圓標籤最大寬度的全域預設值，可被個別 <cluster-node> 的 label-width 覆蓋。
label-gap <cluster-node> CSS 長度 繼承全域預設 覆蓋該子圓到其標籤的距離。
label-width <cluster-node> CSS 長度 繼承全域預設 覆蓋該子圓標籤的最大寬度。

優先順序：<cluster-node label-gap> > <ui-cluster node-label-gap> > UiClusterConfig.nodeLabelGap

範例一：主圓的圓形 → 標籤距離（單層模式）

在 <ui-cluster> 上設定 label-gap，控制主圓底部到文字標籤的垂直距離。 值為任何有效 CSS 長度（px、rem、em）。

label-width 控制標籤 max-width，決定文字在哪裡折行。 較寬的值讓文字分佈更均勻；較窄的值讓標籤更緊湊，折行更早。

範例三：雙層模式 — 子圓全域標籤距離（node-label-gap）

在 <ui-cluster> 上設定 node-label-gap，可統一調整所有子圓到標籤的距離， 不需每個 <cluster-node> 分別設定。

node-label-gap="6px"（預設）

node-label-gap="18px"

範例四：雙層模式 — 子圓個別覆蓋（label-gap / label-width on cluster-node）

每個 <cluster-node> 可獨立設定 label-gap 和 label-width， 覆蓋 <ui-cluster> 的全域預設。 可用來讓標籤文字較長的子圓單獨加寬。

範例五：透過 UiClusterConfig 設定全站預設值

在載入 ui-cluster.js 前，先設定 window.UiClusterConfig， 可改變整個頁面的預設值，無需在每個元素上重複寫屬性。

/* 在 ui-cluster.js 之前執行 */ window.UiClusterConfig = { labelGap: '8px', // 主圓預設距離 labelWidth: '110px', // 主圓預設寬度 nodeLabelGap: '10px', // 子圓預設距離 nodeLabelWidth: '90px' // 子圓預設寬度 };
