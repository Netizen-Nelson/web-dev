ui-reading.js
text-morph 文字原地變形
兩個版本在同一位置淡出淡入切換。<morph-from> 是預設顯示的版本，<morph-to> 是點擊後切換到的版本。巢狀的 margin-pin、chalk-mark、read-pulse 在切換後會自動重新初始化。
範例 A — 基本用法

      

    

    

      
theme="sky"

      
duration="380"

    

    
  


  

    
範例 B — 自訂按鈕文字與速度

    

      

      

    

    

      
label-from="← 還原低分"

      
label-to="看高分版 →"

      
duration="600"

      
theme="ocean"

    

    
  











  

    
    margin-pin
    右邊界浮動註解
  

  

    標記詞底部出現虛線，hover 時說明浮現於視窗右側，虛線從標記詞連至說明框。
    note 屬性支援 <br>、<b> 等 HTML 標籤。
    說明框使用 position: fixed，因此在任何版面配置下都固定出現在螢幕右側。
  


  

    
範例 A — fill 版（實心色塊）

    

      

      

      

    

    

      
note="說明文字"

      
theme="yellow"

    

    
  


  

    
範例 B — outline 版（描邊樣式）

    

      

      

    

    

      
theme="sky-outline"

      
theme="ocean-outline"

      
格式：色票名稱 + -outline

    

    
  











  

    
    read-pulse
    閱讀節奏掃描線
  

  

    段落左側出現一條線從上往下掃過，速度對應建議閱讀時長。
    預設進入視窗自動觸發，也可設為點擊或 hover 觸發。加上 repeat 屬性則可重複播放。
  


  

    
範例 A — visible 觸發（進入視窗自動播放，repeat）

    

      

      

    

    

      
color="teal"

      
speed="3000"

      
trigger="visible"

      
repeat

    

    
  


  

    
範例 B — click 觸發，自訂線寬與左側縮排

    

      

      

    

    

      
trigger="click"

      
pulse-width="5px"

      
gap="20"

      
color="lavender"

    

    
  











  

    
    chalk-mark
    手繪圈選弧線
  

  

    點擊詞彙後，一條 SVG 弧線從左往右動態畫出於文字上方。再點一次消除。
    加上 active 屬性則頁面載入後自動畫出。適合預先標示重點詞，讓讀者也能自行操作。
  


  

    
範例 A — 多色、預設啟動（active）、自訂線寬

    

      

      

    

    

      
theme="focus"

      
thickness="3"

      
active（預設啟動）

      
duration="500"

    

    
  











  

    
    col-pair
    搭配詞同色印記
  

  

    同組搭配詞各自上方有同色小圓點。hover 任何一個成員，同組全部亮起並顯示 title 提示。顏色自動從色盤依序分配，也可用 theme 手動指定。
  


  

    
範例 A — 同段多組搭配詞，自動色盤

    

      

      

    

    

      
group="識別碼"（必填）

      
label="提示文字"

      
theme="sky"（選填，覆蓋色盤）

    

    
  









ui-reading2.js







  

    
    text-diff
    版本差分對比
  

  

    word-level LCS 演算法比對兩段文字，刪除與插入同時呈現。inline 模式在同一行顯示，side 模式兩欄並列。內容以 textContent 進行差分，建議放純文字。
  


  

    
範例 A — inline 模式（刪除線 + 插入底色）

    

      

      

    

    

      
mode="inline"（預設）

      
del-style="strikethrough"

      
theme-del="warning"

      
theme-ins="safe"

    

    
  


  

    
範例 B — inline + del-style="fade"（刪除淡出）

    

      

      

    

    

      
del-style="fade"

      
theme-ins="sky"

      
ins-bg="0.3"

    

    
  


  

    
範例 C — side 模式 + 標籤

    

      

      

    

    

      
mode="side"

      
show-label="true"

      
label-from="原版"

      
label-to="升級版"

    

    
  











  

    
    layer-switch
    多層次分析切換
  

  

    在同一段文字上疊加多個分析維度。切換 toggle 後對應層的標記亮起，其他標記降低透明度。一個 <ls-mark> 可以用空格分隔同時屬於多個層。
  


  

    
範例 A — highlight 樣式，單選，預設啟動 coherence

    

      

      

    

    

      
default="coherence"

      
mark-style="highlight"（預設）

      
layer（ls-mark）="層名稱 [多層用空格]"

    

    
  


  

    
範例 B — underline 樣式，多選（multi），底部 toggle

    

      

      

    

    

      
multi="true"

      
mark-style="underline"

      
toggle-position="bottom"

      
body-dim="true"

    

    
  


  

    
範例 C — box 樣式，dot toggle，啟動時整體文字降透明

    

      

      

    

    

      
mark-style="box"

      
toggle-style="dot"

      
weight="bold"（ls-mark）

    

    
  











  

    
    spotlight
    段落聚焦
  

  

    點擊任何 <spotlight> 段落後，全頁面其他內容被半透明遮罩蓋住，只有被點擊的段落浮出。同頁所有 spotlight 共用一組遮罩，可以直接點擊另一段落切換聚焦。按 Escape 或點背景關閉。
  


  

    
範例 A — 四種不同配置，點擊任一段落聚焦

    

      

      

    

    

      
theme="focus"

      
ring-style="solid | dashed | dotted"

      
dim="0.08 ~ 0.3"

      
ring="false"（無邊框）

      
hint="false"（無提示圖示）
