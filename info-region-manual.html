<info-region> 元件說明書

逐步展示內容區塊的輕量 Web Component，支援鏈結、倒數、手動推進、群組控制與折行水平佈局。

無框架依賴 Custom Elements v1 Bootstrap Grid 相容

快速開始

① 引入腳本

HTML
<!-- 元件核心腳本 -->
<script src="./info-region.js"></script>

<!-- 水平折行佈局需要 Bootstrap Grid -->
<link rel="stylesheet"
  href="https://cdn.jsdelivr.net/npm/bootstrap@5/dist/css/bootstrap-grid.min.css">

② 放入標記

HTML
<info-region active="true" color="sky">
  <p>這個區塊已啟動。</p>
</info-region>

元素出現時以動畫從 max-height: 0 展開，左側顯示色彩邊框。不需要寫任何額外 CSS 或 JavaScript。

提示 所有外觀與行為都透過 HTML 屬性設定。進階的程式化控制可選用 window.InfoRegion API。

設計概念

每個 <info-region> 預設隱藏，加上 active="true" 後以動畫展開。多個區塊用 next 屬性首尾相連，形成一條自動接力的展示鏈。

#step1
─ next ──▶
#step2
─ next ──▶
#step3
─ next ──▶
（終止）

每個節點啟動後，依三種策略之一決定何時喚醒下一節點：

  • 延遲自動：next-interval 毫秒後自動觸發（預設）
  • 倒數計時：countdown 倒數條跑完後觸發
  • 手動確認：manual 顯示按鈕，使用者點擊後觸發

<info-region-group> 包住一組區塊，自動加上「開始 / 重設」按鈕，並可選擇性顯示整體進度條。

靜態顯示與切換

最簡單的用法：直接設定 active="true"，在頁面載入時就顯示區塊。

範例 1  靜態顯示 入門

這個區塊在頁面載入時就已展開，使用預設的 sky 色彩。
HTML
<info-region active="true">
  <p>這個區塊在頁面載入時就已展開。</p>
</info-region>
範例 2  程式化切換

由 JavaScript 設定 active 屬性來控制顯示與隱藏。
HTML + JS
<info-region id="box">
  <p>由 JavaScript 控制的區塊。</p>
</info-region>

<button onclick="document.getElementById('box').setAttribute('active','true')">
  啟動
</button>
<button onclick="document.getElementById('box').reset()">
  隱藏
</button>
說明 元素本身提供 .activate() 與 .reset() 方法，等同於手動設定 / 移除 active 屬性，並自動清除倒數條與手動按鈕。

步驟鏈結

用 next 指向下一個元素的 ID，當前區塊啟動後延遲 next-interval 毫秒自動啟動目標元素。鏈的最後一個節點不設 next。

範例 4  三步驟自動鏈結 實作

步驟 1：介紹背景知識。啟動後 600ms 自動進入步驟 2。

步驟 2：說明核心概念。啟動後 600ms 進入步驟 3。

步驟 3：展示實際應用。鏈結在此終止。
HTML
<!-- next 指向下一個元素的 id -->
<info-region id="step1" color="sky"
             next="step2" next-interval="600">
  <p>步驟 1：介紹背景知識。</p>
</info-region>

<info-region id="step2" color="safe"
             next="step3" next-interval="600">
  <p>步驟 2：說明核心概念。</p>
</info-region>

<!-- 最後一個不設 next，鏈結在此終止 -->
<info-region id="step3" color="special">
  <p>步驟 3：展示實際應用。</p>
</info-region>

<button onclick="document.getElementById('step1').activate()">
  ▶ 啟動
</button>
說明 next-interval 預設為全域設定 InfoRegionConfig.defaultInterval（500ms）。可在元素上個別覆蓋，不影響其他步驟。

倒數進度條

在有 next 的元素上加 countdown（毫秒），啟動後底部顯示一條從右往左縮減的進度條；時間耗盡才觸發下一步，讓使用者有足夠時間閱讀。

範例 5  2 秒倒數後接力

步驟 1：底部進度條倒數 2 秒後自動進入步驟 2。

步驟 2：抵達！
HTML
<info-region id="step1" color="sky"
             countdown="2000"
             next="step2">
  <p>底部進度條倒數 2 秒後進入步驟 2。</p>
</info-region>

<info-region id="step2" color="safe">
  <p>抵達！</p>
</info-region>

倒數條細節屬性

屬性說明預設
countdown倒數總時長（ms）；設定後啟用倒數條—
countdown-height進度條高度（px）3
countdown-positionbottom 或 topbottom
countdown-color進度條色彩（品牌色鍵）與 color 同

手動推進

加上布林屬性 manual，區塊啟動後不自動跳轉，而是顯示一個可自訂的「下一步」按鈕，等使用者點擊後才繼續。

範例 6  手動確認後繼續

步驟 1：請閱讀完這段說明，再點擊右側按鈕繼續。

步驟 2：繼續成功！
HTML
<info-region id="step1" color="sky"
             manual
             next="step2"
             manual-label="我知道了，繼續 ▶"
             manual-align="right">
  <p>閱讀後點擊按鈕繼續。</p>
</info-region>

<info-region id="step2" color="special">
  <p>繼續成功！</p>
</info-region>
屬性說明預設
manual布林屬性，設定即啟用手動推進—
manual-label按鈕顯示文字▶ 下一步
manual-color按鈕色彩（品牌色鍵）與 color 同
manual-alignleft / center / rightright

群組基礎

用 <info-region-group> 包住多個 <info-region>，頂部自動產生「▶ 開始」和「↺ 重設」兩個控制按鈕，一鍵管理整條鏈。

範例 7  最簡群組 常用

步驟 1：點「▶ 開始」後展開，500ms 後接力步驟 2。

步驟 2：自動接力中。

步驟 3：完成。
HTML
<info-region-group>

  <info-region id="step1" color="sky"
               next="step2" next-interval="500">
    <p>步驟 1</p>
  </info-region>

  <info-region id="step2" color="safe"
               next="step3" next-interval="500">
    <p>步驟 2</p>
  </info-region>

  <info-region id="step3" color="special">
    <p>步驟 3</p>
  </info-region>

</info-region-group>

自訂按鈕標籤與色彩

HTML
<info-region-group
  start-label="▶ 播放說明"
  reset-label="↺ 再看一次"
  start-color="safe"
  reset-color="stone">
  ...
</info-region-group>
提示 設定 show-controls="false" 隱藏控制列，搭配 auto-start 讓群組在頁面載入後自動播放，適合說明動畫等場景。

整體進度條

在 <info-region-group> 上加 global-progress，出現一條橫跨所有步驟的進度條，即時反映已啟動比例。搭配 show-percent 可同時顯示百分比數字。

範例 8  帶進度條的四步驟群組 常用

步驟 1

步驟 2

步驟 3

步驟 4
HTML
<info-region-group
  global-progress
  progress-color="sky"
  show-percent>

  <info-region id="s1" color="sky"
               next="s2" next-interval="600"><p>步驟 1</p></info-region>
  <info-region id="s2" color="safe"
               next="s3" next-interval="600"><p>步驟 2</p></info-region>
  <info-region id="s3" color="special"
               next="s4" next-interval="600"><p>步驟 3</p></info-region>
  <info-region id="s4" color="lavender"><p>步驟 4</p></info-region>

</info-region-group>
屬性說明預設
global-progress布林，啟用整體進度條—
progress-color進度條色彩（品牌色鍵）defaultColor
progress-height進度條高度（px）4
progress-positiontop 或 bottombottom
show-percent布林，顯示完成百分比—

連鎖啟動

設定 cascade-interval（毫秒）後，點「開始」時每個步驟依序交錯展開，不需要設定 next 鏈結，適合所有步驟同時呈現、只是時間錯開的版面。

範例 9  每 200ms 一個依序展開

① 第 1 個（立即）

② 第 2 個（200ms 後）

③ 第 3 個（400ms 後）

④ 第 4 個（600ms 後）
HTML
<!-- cascade-interval 啟動後不需要 next 屬性 -->
<info-region-group cascade-interval="200">
  <info-region color="sky">      <p>① 第 1 個（立即）</p>     </info-region>
  <info-region color="safe">     <p>② 第 2 個（200ms 後）</p> </info-region>
  <info-region color="special">  <p>③ 第 3 個（400ms 後）</p> </info-region>
  <info-region color="lavender"> <p>④ 第 4 個（600ms 後）</p> </info-region>
</info-region-group>
注意 cascade-interval 啟用時，各節點的 next、countdown、manual 均不觸發，群組接管整個啟動順序。若需要每步驟有不同的等待策略，請改用標準鏈結模式。

水平折行佈局

在 <info-region-group> 設定 layout="horizontal"，步驟改為並排。超過 cols-per-row（預設 4）的步驟自動折到下一列，形成多列網格。

範例 10  8 個步驟，每列 4 個（預設） 新功能

① 準備環境

② 安裝依賴

③ 設定組態

④ 資料初始化

⑤ 啟動服務

⑥ 功能測試

⑦ 效能調校

⑧ 正式上線
HTML
<!--
  layout="horizontal"   水平並排
  cols-per-row="4"      每列 4 個（這是預設值，可省略）
  cascade-interval="100" 每隔 100ms 展開一個
-->
<info-region-group
  layout="horizontal"
  cols-per-row="4"
  cascade-interval="100">

  <info-region color="sky">      <p>① 準備環境</p>  </info-region>
  <info-region color="safe">     <p>② 安裝依賴</p>  </info-region>
  <info-region color="special">  <p>③ 設定組態</p>  </info-region>
  <info-region color="lavender"> <p>④ 資料初始化</p></info-region>
  <!-- 第 5 個開始自動折行為第二列 -->
  <info-region color="stone">    <p>⑤ 啟動服務</p>  </info-region>
  <info-region color="pink">     <p>⑥ 功能測試</p>  </info-region>
  <info-region color="orange">   <p>⑦ 效能調校</p>  </info-region>
  <info-region color="focus">    <p>⑧ 正式上線</p>  </info-region>

</info-region-group>
範例 11  9 個步驟，每列 3 個，列間距 24px
HTML
<info-region-group
  layout="horizontal"
  cols-per-row="3"
  row-gap="24px"
  cascade-interval="100">

  <info-region color="sky">     <p>① …</p></info-region>
  <info-region color="safe">    <p>② …</p></info-region>
  <info-region color="special"> <p>③ …</p></info-region>
  <!-- 第二列 -->
  <info-region color="lavender"><p>④ …</p></info-region>
  <info-region color="stone">   <p>⑤ …</p></info-region>
  <info-region color="pink">    <p>⑥ …</p></info-region>
  <!-- 第三列 -->
  <info-region color="orange">  <p>⑦ …</p></info-region>
  <info-region color="focus">   <p>⑧ …</p></info-region>
  <info-region color="indigo">  <p>⑨ …</p></info-region>

</info-region-group>
屬性說明預設
layout設為 horizontal 啟用水平折行佈局—（垂直）
cols-per-row每列顯示幾個步驟，自動換算 Bootstrap 欄位 class4
row-gap列與列之間的間距（需含 CSS 單位）16px
gutterBootstrap gutter class（欄間距）g-3
col-class完整覆蓋欄位 class，自行指定則不自動計算—（自動）

自動欄位對照：1 欄 → col-12，2 欄 → col-md-6，3 欄 → col-md-4 col-sm-6，4 欄 → col-md-3 col-sm-6，6 欄 → col-md-2 col-sm-4，其他 → col-md col-sm-6。

必要條件 水平折行佈局依賴 Bootstrap Grid CSS。請確認頁面已引入 bootstrap-grid.min.css，否則欄位不會正確排列。

框線客製化

預設只有左側邊框（4px solid）。透過 border-width 可擴展到四邊，border-{side}-* 系列屬性則可個別控制每一邊的粗細與樣式。

範例 12  四邊框與虛線樣式

border-width="2"：四邊各 2px solid。

border-top/bottom-style="dashed"：上下虛線，左右無框。
HTML
<!-- border-width 同時設定四邊 -->
<info-region active="true" color="sky" border-width="2">
  <p>四邊各 2px solid。</p>
</info-region>

<!-- 個別邊設定覆蓋全域設定 -->
<info-region active="true" color="special"
             border-top-width="3"      border-bottom-width="3"
             border-left-width="0"
             border-top-style="dashed" border-bottom-style="dashed">
  <p>上下虛線，左右無框。</p>
</info-region>
屬性說明預設
border-width四邊框線粗細（px 整數）左 4，其餘 0
border-style四邊框線樣式solid
border-{side}-width個別邊粗細，覆蓋 border-width—
border-{side}-style個別邊樣式，覆蓋 border-style—

可用樣式值：solid / dashed / dotted / double / groove / ridge / inset / outset

全域設定

在引入 info-region.js 之前定義 window.InfoRegionConfig 物件，可一次調整所有元素的預設值，不必在每個標籤上重複設定屬性。

必須在腳本載入前設定 window.InfoRegionConfig 必須在 info-region.js 之前定義。腳本在解析時就會讀取並合併設定，之後修改物件無效。元素屬性的優先順序永遠高於全域設定。
範例 13  常見全域設定
JS（放在 info-region.js 之前）
window.InfoRegionConfig = {
  /* ── 色彩與動畫 ────────────────────────── */
  defaultColor:       'safe',     // 預設邊框色（品牌色鍵）
  animDuration:       400,        // 垂直展開動畫（ms）
  horizontalAnimDur:  300,        // 水平淡入動畫（ms）
  defaultInterval:    600,        // 無 countdown 的鏈結延遲（ms）

  /* ── 外觀 ───────────────────────────────── */
  borderWidth:        4,          // 左側框線預設粗細（px）
  borderRadius:       '0 8px 8px 0',
  bgColor:            '#1e1f1e',  // 區塊背景色
  textColor:          '#C6C7BD',  // 文字色
  fontSize:           '1rem',
  padding:            '14px 20px 20px 20px',
  marginBottom:       '12px',

  /* ── 倒數與進度條 ───────────────────────── */
  countdownHeight:    4,
  countdownPosition:  'bottom',
  progressHeight:     5,
  progressPosition:   'bottom',
  progressTransition: 400,

  /* ── 手動按鈕 ───────────────────────────── */
  manualLabel:        '繼續 ▶',
  manualAlign:        'right',

  /* ── 群組 ───────────────────────────────── */
  cascadeInterval:    0,          // 0 = 停用連鎖啟動
  colsPerRow:         4,          // 水平佈局每列欄數

  /* ── 按鈕尺寸（start / reset 共用） ────── */
  btnFontSize:        '0.9rem',
  btnPadding:         '8px 20px',

  /* ── 個別按鈕尺寸（覆蓋共用值） ─────────── */
  startBtnWidth:      null,       // 例如 '120px'
  resetBtnWidth:      null,
};

公開 API

腳本載入後，window.InfoRegion（可省略 window.）提供程式化控制介面。

範例 14  API 操作
JavaScript
// 啟動指定 id 的 info-region
InfoRegion.activate('step3');

// 重設頁面上所有 info-region
InfoRegion.resetAll();

// 只重設某群組內的 info-region（傳入 CSS 選擇器）
InfoRegion.resetAll('#my-group info-region');

// 取得所有可用色彩名稱（字串陣列）
console.log(InfoRegion.colors);
// → ['shell', 'lavender', 'special', 'warning', ...]

// 取得目前生效設定的唯讀快照
const cfg = InfoRegion.config;
console.log(cfg.defaultColor);   // 'sky'
console.log(cfg.animDuration);   // 500

// ── 元素本身也有方法 ──────────────────────────────
const el = document.getElementById('step1');
el.activate();  // 等同於 setAttribute('active', 'true')
el.reset();     // 等同於 removeAttribute('active')，並清除倒數條與手動按鈕
成員說明
InfoRegion.activate(id)啟動指定 id 的元素；找不到時輸出 console.warn
InfoRegion.resetAll(selector?)重設所有（或 selector 範圍內）的 info-region；預設選取全部
InfoRegion.colors所有品牌色鍵名的陣列（唯讀）
InfoRegion.config目前設定的快照物件（唯讀副本，修改不影響實際設定）
