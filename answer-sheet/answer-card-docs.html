AnswerCard 使用說明

v1.0 零依賴 純 JS

側邊滑入式答題卡元件。支援動態題數、2–5 個選項、單欄與雙欄模式， 提供完整的尺寸、間距、顏色客製化系統以及全域預設值機制。 所有 CSS 與 JS 整合於單一 <script>，無需額外依賴或建置工具。

快速開始

將 AnswerCard class 程式碼複製至頁面 <script> 標籤，建立實例即可使用。

引入方式

<!-- 在 </body> 前引入，之後的 <script> 即可使用 AnswerCard -->
<script src="answer-card.js"></script>
<script>
  const card = new AnswerCard({ ... });
</script>

最小用法

// 建立 40 題、4 選項的答案卡（靠右，預設收合）
const card = new AnswerCard({
  totalQuestions: 40,
  optionCount:    4,
});

常見設定組合

const card = new AnswerCard({
  totalQuestions: 50,
  optionCount:    4,
  twoColumns:     true,
  panelTitle:     '英語科測驗答案卡',
  panelSide:      'right',
  exportLabel:    '匯出答案',
  exportFileName: 'exam-answers',
  onChange: (q, opt, all) => {
    console.log(`第 ${q} 題 → ${opt ?? '（取消）'}`);
  },
});

// 手動開啟面板
card.open();

面板佈局

控制答案卡面板的位置、尺寸、標題文字。面板寬度完全可自訂，單欄與雙欄模式各自獨立設定。

屬性名稱型別預設值說明
panelSidestring 'right' 面板出現的邊，可設為 'right' 或 'left'。切換按鈕位置、陰影方向、圓角位置均會自動對應調整。
panelWidthstring '268px' 單欄模式時面板的寬度，接受任何有效 CSS 寬度（px、rem、vw 等）。
panelWidthTwoColstring '450px' 雙欄模式時面板的寬度。建議為 panelWidth 的 1.6–1.8 倍，確保圓圈有足夠空間。
twoColumnsboolean false 啟用雙欄排版。題目以直向填欄排列（左欄先填滿後接右欄），符合標準答題卡習慣。
panelPaddingstring '14px' 面板 header、body、footer 的左右內距。
panelTitlestring '答案卡' 顯示在面板頂部標題列的文字。
panelTitleSizestring '0.95rem' 標題文字的字體大小，接受任何 CSS font-size 值。
注意：配置在 new AnswerCard() 時決定。若需執行期動態切換（如雙欄改單欄），請先呼叫 card.destroy() 再重新建立實例。

切換按鈕

固定貼邊的切換按鈕，包含方向箭頭、直向進度條與完成百分比。按鈕與面板同步滑動，箭頭方向隨開關狀態自動翻轉。

屬性名稱型別預設值說明
toggleOffsetTopstring '28vh' 切換按鈕距頁面頂端的距離，接受任何 CSS 值（px、vh 等）。若頁面有固定 header，建議設為 header 高度加上適當間距，例如 '72px'。
toggleSizestring '34px' 切換按鈕的寬度，高度由箭頭 + 進度條 + 百分比自動決定。

題目設定

屬性名稱型別預設值說明
totalQuestionsnumber 40 題目總數，決定答案卡的圓圈列數量，動態傳入，無上限。
optionCountnumber 4 每題的選項數量，可設為 2、3、4 或 5。對應字母依序為 A、B、C、D、E（截取前 N 個）。全部題目共用相同的選項數量。
提示：選項標籤固定為 A B C D E 前 N 個字母。若需自訂標籤（如數字 1 2 3 4），可修改元件內 _buildDOM() 方法中的 labels 陣列。

圓圈外觀

控制選項圓圈與題目列的尺寸、間距配置。雙欄模式可設定獨立的圓圈尺寸。

屬性名稱型別預設值說明
circleSizestring '1.85rem' 單欄模式下圓圈的直徑（同時為寬與高）。
circleSizeTwoColstring '1.5rem' 雙欄模式下圓圈的直徑。空間較窄時建議設為 circleSize 的 80% 左右。
borderWidthstring '2px' 未選取圓圈的邊框線條粗細。
optionGapstring '4px' 同一題各選項圓圈之間的水平間距（A 與 B 之間等）。
questionGapstring '4px' 題目列之間的垂直間距（grid row-gap）。
columnGapstring '12px' 雙欄模式兩欄之間的水平間距（grid column-gap），僅 twoColumns: true 時生效。
cellPaddingVstring '3px' 每個題目列的上下 padding。
cellPaddingHstring '3px' 每個題目列的左右 padding。

字型

屬性名稱型別預設值說明
fontSizestring '0.82rem' 選項圓圈內字母（A、B、C、D）的字體大小。
qNumFontSizestring '0.72rem' 題號數字的字體大小。
fontFamilystring 'system-ui, sans-serif' 元件整體字型族，套用至圓圈字母、題號、標題、匯出按鈕等所有文字。

顏色：面板結構

屬性名稱型別預設值說明
panelBgstring '#181918' 題目區域（body）的背景色。
headerBgstring '#0F100F' 頂部標題列的背景色。
footerBgstring '#0F100F' 底部匯出按鈕列的背景色。
dividerColorstring '#1A1B18' header / body / footer 之間分隔線的顏色。

顏色：文字

屬性名稱型別預設值說明
titleColorstring '#C6C7BD' 面板標題（panelTitle）的文字顏色。
statsColorstring '#5A5B57' 標題列右側作答統計（如「12 / 50」）的文字顏色。
qNumColorstring '#4A4B47' 未作答題目的題號顏色（偏暗，作為背景色的一部分）。
qNumAnsweredColorstring '#C8DD5A' 已作答題目的題號顏色。作答後題號亮起，提供一眼掃描全卷進度的視覺回饋。

顏色：圓圈

共有三種視覺狀態：未選取、懸停（hover）、已選取（selected）。

屬性名稱型別預設值說明
未選取狀態
circleBorderColorstring '#4A4B47' 未選取圓圈的邊框顏色。
circleTextColorstring '#6B6C68' 未選取圓圈內字母的顏色。
懸停狀態（hover）
hoverBgstring 'rgba(195,165,229, 0.10)' 懸停時圓圈的背景色，接受任何 CSS 顏色（含 rgba 半透明值）。
hoverBorderstring '#C3A5E5' 懸停時圓圈的邊框顏色。
hoverTextstring '#C3A5E5' 懸停時圓圈內字母的顏色。
已選取狀態（selected）
selectedBgstring '#C8DD5A' 已選取圓圈的填充背景色。
selectedBorderstring '#C8DD5A' 已選取圓圈的邊框顏色（通常與 selectedBg 相同）。
selectedTextstring '#0C0D0C' 已選取圓圈內字母的顏色。建議使用深色以與亮色填充背景形成對比。
再次點擊取消：點擊已選取的同一選項可取消答案，題號恢復暗色，圓圈回到未選取狀態，onChange 也會觸發（opt 為 null）。

顏色：切換按鈕與進度條

屬性名稱型別預設值說明
toggleBgstring '#7B6CF0' 切換按鈕的背景色。
toggleTextColorstring '#FFFFFF' 切換按鈕內箭頭符號及百分比文字的顏色。
progressTrackstring '#14150F' 進度條軌道（未完成部分）的顏色。
progressFillstring '#C8DD5A' 進度條填充（已作答比例）的顏色，由底部往上增長。

顏色：Focus Ring（鍵盤聚焦）

使用 Tab 鍵在圓圈之間切換時顯示的外框指示。僅在 :focus-visible 時出現，滑鼠點擊不觸發。

屬性名稱型別預設值說明
focusRingColorstring '#A0CF72' 聚焦外框的顏色。
focusRingWidthstring '2px' 聚焦外框的線條粗細（CSS outline-width）。
focusRingOffsetstring '2px' 聚焦外框與圓圈邊緣的間距（CSS outline-offset）。

匯出按鈕

顯示在面板底部。點擊後自動觸發下載 .json 格式的答案檔案，無需後端介入。

屬性名稱型別預設值說明
exportLabelstring '匯出答案 JSON' 按鈕的顯示文字，可自訂為任何說明文字。
exportFontSizestring '0.88rem' 按鈕文字的字體大小。
exportPaddingstring '9px 16px' 按鈕的內距（CSS padding 語法）。
exportBgstring '#40C99A' 按鈕的背景色。
exportHoverBgstring '#35B088' 按鈕懸停時的背景色。
exportColorstring '#0C0D0C' 按鈕的文字顏色。
exportFileNamestring 'answers' 下載檔案的名稱（不含副檔名）。最終產生 answers.json。
exportRadiusstring '6px' 按鈕的圓角半徑。

匯出 JSON 格式

{ "note": "EXAM_2025_001", ← 固定輸出，即使為空字串 "memo": "STU_A123456", "answers": { "1": "A", "2": "C", "3": null, ← 未作答 "4": "B", ... "50": "D" } }

note 與 memo 固定出現在頂層，即使為空字串亦然。answers 內每個題號對應選項字母，未作答為 null。

元資料屬性

屬性名稱型別預設值說明
notestring '' 自訂備註欄位，建議用來存放試卷 ID。不論是否為空字串，匯出時固定輸出。
memostring '' 自訂備忘欄位，建議用來存放作答者 ID。不論是否為空字串，匯出時固定輸出。 
// 帶入試卷 ID 與作答者 ID 的典型用法
const card = new AnswerCard({
  totalQuestions: 50,
  note: 'EXAM_2025_001',   // 試卷 ID
  memo: 'STU_A123456',    // 作答者 ID
});

回呼函數

屬性名稱型別預設值說明
onChangefunction null 每次作答或取消選取時觸發，簽名為 (q, opt, allAnswers)。

參數說明

const card = new AnswerCard({
  onChange: (q, opt, allAnswers) => {
    // q          : number  — 題號，從 1 起算
    // opt        : string | null  — 選取的字母 ('A'~'E')，取消時為 null
    // allAnswers : Object  — 當前所有答案的快照（僅含已作答的題目）

    console.log(`第 ${q} 題 → ${opt ?? '取消'}`);
    console.log('目前已答題數:', Object.keys(allAnswers).length);
  },
});
注意：allAnswers 是快照副本，只含已作答的題號鍵；已取消的題目不會出現在其中。如需取得含 null 的完整結構，請呼叫 card.getAnswers()。

公開 API 方法

方法參數回傳說明
open()— void 滑入展開面板，切換按鈕箭頭方向更新。
close()— void 滑出收合面板，切換按鈕箭頭方向更新。
toggle()— void 若已收合則展開，若已展開則收合。
getAnswers()— Object 回傳所有題目的答案物件。格式：{ 1: 'A', 2: null, 3: 'C', ... }。未作答的題目值為 null，題號鍵為數字型別。
setAnswers(data)Object void 批次載入預存答案，常用於恢復作答進度。格式同 getAnswers()，null 與空值鍵會被略過。
getSummary()— Object 回傳作答統計。格式：{ total, answered, unanswered, percentage }，percentage 為整數 0–100。
reset()— void 清除所有答案，還原全部圓圈與題號至初始狀態，進度條歸零。
destroy()— void 從 DOM 移除面板、切換按鈕及注入的 <style> 元素，釋放所有資源。

使用片段

// 讀取全部答案
const answers = card.getAnswers();
// → { 1: 'A', 2: null, 3: 'C', ..., 50: 'D' }

// 載入預存進度
card.setAnswers({ 1: 'B', 2: 'A', 3: 'C' });

// 取得統計
const s = card.getSummary();
// → { total: 50, answered: 3, unanswered: 47, percentage: 6 }

// 送出前確認
if (s.unanswered > 0) {
  card.open();
  return;
}

// 傳送至後端
fetch('/api/submit', {
  method: 'POST',
  headers: { 'Content-Type': 'application/json' },
  body: JSON.stringify(card.getAnswers()),
});

全域設定 AnswerCard.config()

在建立任何實例之前呼叫 AnswerCard.config()，可永久覆寫所有後續實例的預設值。實例層級的選項仍可個別覆寫全域設定。

優先序

元件內建預設值
→
AnswerCard.config()
→
new AnswerCard( opts )
右側優先 
// 必須在 new AnswerCard() 之前呼叫
AnswerCard.config({
  // 全站改用藍色主題
  selectedBg:     '#4285EB',
  selectedBorder: '#4285EB',
  selectedText:   '#FFFFFF',
  toggleBg:       '#4285EB',
  progressFill:   '#4285EB',

  // 全站面板靠左
  panelSide: 'left',
});

// 繼承全域設定
const card1 = new AnswerCard({ totalQuestions: 30 });

// 覆寫單一實例的 toggleBg（其他仍沿用全域）
const card2 = new AnswerCard({
  totalQuestions: 50,
  toggleBg: '#7B6CF0',
});

範例：整合自動存檔

const SAVE_KEY = 'exam_progress';

const card = new AnswerCard({
  totalQuestions: 50,
  optionCount:    4,
  twoColumns:     true,
  onChange: (q, opt, all) => {
    // 每次答題自動存至 sessionStorage
    sessionStorage.setItem(SAVE_KEY, JSON.stringify(all));
  },
});

// 頁面載入時嘗試恢復進度
const saved = sessionStorage.getItem(SAVE_KEY);
if (saved) {
  try {
    card.setAnswers(JSON.parse(saved));
    console.log('進度已恢復', card.getSummary());
  } catch (e) {
    sessionStorage.removeItem(SAVE_KEY);
  }
}
注意：sessionStorage 在關閉分頁後會清除。若需跨頁面持久化，改用 localStorage，或搭配 onChange 回呼向後端即時儲存。

範例：送出前驗證

document.getElementById('submit-btn')
  .addEventListener('click', async () => {

  const summary = card.getSummary();

  // 仍有未作答題目 → 展開答案卡提示
  if (summary.unanswered > 0) {
    card.open();
    showAlert(`尚有 ${summary.unanswered} 題未作答，請確認。`);
    return;
  }

  const answers = card.getAnswers();

  try {
    const res = await fetch('/api/exam/submit', {
      method:  'POST',
      headers: { 'Content-Type': 'application/json' },
      body:    JSON.stringify({
        examId:      'EXAM_2025_001',
        answers:     answers,
        submittedAt: new Date().toISOString(),
      }),
    });

    if (res.ok) {
      card.destroy();                  // 成功後移除答案卡
      sessionStorage.removeItem(SAVE_KEY);
      showAlert('答案已成功送出！');
    }
  } catch (err) {
    showAlert('送出失敗，請檢查網路連線後重試。');
  }
});
