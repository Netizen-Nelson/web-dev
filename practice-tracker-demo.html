語意標籤結構

practice-tracker面板外框，fixed 定位，自動注入至 body
pt-header標題列，點擊收合
pt-title標題文字
pt-toggle收合符號（− / +）
pt-body可收合的主體區域
pt-grid格子容器，CSS Grid 排列
pt-cell單一格子，完成後加 .is-done
pt-count「2 / 5 完成」計數文字
pt-complete全部完成時顯示
pt-complete-sub完成副標（選填）

觸發方式

方式一：bp-stepper 自動觸發（watchStepper: true）
stepper 走到最後一步時發出 bps:complete，元件自動找最近的 section[id^="ex-"] 打格子。

方式二：自定義事件手動觸發（非 stepper 練習）
document.dispatchEvent(new CustomEvent('pt:stage-complete', { detail: { sectionId: 'ex-2' } }))

方式三：公開 API 直接呼叫
window.PracticeTracker.markDone('ex-3')

section#ex-1

階段一：辨認後位修飾

以下句子的主詞是哪個字？後位修飾片語的範圍是哪裡？

Adults caring for an aging spouse and regularly helping them with household tasks report that this has had a positive impact.
主詞：adults　動詞：report　後位修飾：caring for an aging spouse...
section#ex-2

階段二：中英語序對比

把以下中文改成英文語序（名詞先出，修飾往後掛）

「讓我認識不同背景的人的那段交換學生經歷」
提示：先說 the exchange experience，再接關係子句
→ the exchange experience that gave me a chance to meet people from different backgrounds
section#ex-3　← bps:complete 自動觸發

階段三：四種後位修飾（stepper 走完自動打格子）

點擊「下一種」走完全部四種，格子自動完成，無需手動按鈕。

① 現在分詞片語：adults caring for an aging spouse
② 過去分詞片語：a habit formed during the COVID-19 pandemic
③ 介系詞片語：users of social media and AI chatbots
④ 關係子句：a habit that I managed to stick with

section#ex-4

階段四：sedentary lifestyle 造句

用後位修飾結構，把 sedentary lifestyle 放進一個口說 Part 3 答案裡。

題目：Do you think people today have a healthy lifestyle?
參考答案：Most office workers in Taipei lead a sedentary lifestyle shaped entirely by desk jobs and long commutes, even if they hit the gym twice a week.
section#ex-5　← PracticeTracker.markDone() API 示範

階段五：自由造句提交

用本頁學到的任一後位修飾結構，自己造一句話，然後點「提交」。（此階段示範 API 直接呼叫）

覆蓋設定範例

在載入 practice-tracker.js 之前宣告： 
window.PracticeTrackerConfig = {
  prefix:          'ex-',
  position:        'bottom-left',   // 改成左下角
  cellSize:        '20px',          // 格子放大
  cellsPerRow:     4,
  colorDone:       '#0DA591',       // teal
  colorComplete:   '#C3A5E5',       // lavender
  title:           'My Progress',
  completeText:    '都做完了！',
  completeSubText: '繼續下一集',
  collapsed:       true,            // 預設收合
  offsetY:         '40px',
};
