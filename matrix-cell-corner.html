屬性 說明 預設值
filled filled 布林屬性，presence 即啟用。整格填滿 theme.accent， 前景（文字與圖示）強制 #0C0D0C。 存在時 corner 自動忽略。 （停用）
corner corner 布林屬性，presence 即啟用右上角三角摺角。filled 存在時無效。 （停用）
corner-size corner 三角形直角邊長，單位 px（整數）。 30
corner-color corner 三角形色。接受 palette key 或任意 CSS 色值。 theme.accent
corner-icon corner 覆蓋在三角上的 Bootstrap Icon class，如 bi-star-fill。省略則無圖示。 （無）
corner-icon-color corner icon 色。接受 palette key 或任意 CSS 色值。 #0C0D0C
