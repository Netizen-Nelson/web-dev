屬性速查

ui-cluster

兩層 Burst Cluster 元件——圓點數字暗示內容量，點擊逐層展開

基本用法

主圓數字自動計算 <cluster-node> 數量； 子圓數字自動計算 <cluster-item> 數量。 點擊主圓後爆開，子圓依序出現；點擊子圓展開內容列表。 

<ui-cluster theme="lavender" label="寫作題型">

  <cluster-node label="Task 1 圖表">
    <cluster-item>長條圖比較練習</cluster-item>
    <cluster-item>折線圖趨勢描述</cluster-item>
    <cluster-item>圓餅圖百分比</cluster-item>
  </cluster-node>

  <cluster-node label="Task 2 議論">
    <cluster-item>同意/不同意</cluster-item>
    <cluster-item>討論兩個觀點</cluster-item>
  </cluster-node>

  <cluster-node label="Task 2 混合">
    <cluster-item>問題與解決方案</cluster-item>
  </cluster-node>

</ui-cluster>
點擊主圓 → 點擊子圓
長條圖比較練習 折線圖趨勢描述 圓餅圖百分比說明 同意／不同意題型 討論兩個觀點 問題與解決方案

theme 色系

theme 屬性接受所有品牌色名稱或 HEX 值。 子圓若未設定 theme，自動繼承主圓顏色。

尺寸與間距

size 控制主圓直徑，node-size 控制子圓直徑， gap 控制子圓間距。三者皆可接受任意 CSS 長度值。

子圓各自設定 theme

每個 <cluster-node> 可獨立設定 theme（或 color）， 未設定時繼承主圓顏色。展開區塊的邊框顏色跟隨子圓顏色。

重設按鈕

在 <ui-cluster> 加上 reset 屬性， 右上角出現重設按鈕，點擊後整個元件回到初始圓形狀態，可重新互動。

雅思教學完整場景

模擬真實教學頁面：一個主題下有多個子題， cluster-item 內容支援任意 HTML，可放題目、例句、連結等。

單層模式 — 直接展開內容

省略 <cluster-node>，直接在 <ui-cluster> 下放 <cluster-item>，點擊主圓後直接展開內容列表，一次完成，不需要第二層點擊。 數字 = cluster-item 數量。 

<ui-cluster theme="teal" label="常見題型" reset>
  <cluster-item>True / False / Not Given</cluster-item>
  <cluster-item>Matching Headings</cluster-item>
  <cluster-item>Summary Completion</cluster-item>
</ui-cluster>
