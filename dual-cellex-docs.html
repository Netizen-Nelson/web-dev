雙欄格元件完整使用說明書 — 程式碼與預覽對照

安裝與引入

將 dual-cellex.js 置於同目錄，在 <body> 末尾引入即可，無外部相依。

引入腳本
<script src="dual-cellex.js"></script>

三種初始化方式

① JS API（最靈活）

對任意 <div id="..."> 直接 new DualCell(id, options)，子元素使用自訂標籤。

JS API 初始化 
<div id="my-table">
  <dual-col>產品</dual-col>
  <dual-col>單價</dual-col>
  <dual-col>MacBook Pro</dual-col>
  <dual-col>NT$ 89,900</dual-col>
  <dual-col>iPad Air</dual-col>
  <dual-col>NT$ 23,900</dual-col>
</div>

<script>
  new DualCell('my-table', { theme: 'lavender' });
</script>

② Custom Element <dual-cell>

使用自訂 HTML 標籤，屬性名稱以 kebab-case 對應選項，適合純 HTML 工作流。

Custom Element 初始化 
<dual-cell id="ce-demo"
           theme="sky"
           cols="2">
  <dual-col>指標</dual-col>
  <dual-col>本月數值</dual-col>
  <dual-col>訪客數</dual-col>
  <dual-col>12,480</dual-col>
</dual-cell>

③ data-dual-cell 屬性自動初始化

掛上 data-dual-cell 屬性，所有選項透過 data-* 傳入，DOMContentLoaded 後自動執行。

data-dual-cell 自動初始化 
<div id="auto-demo"
     data-dual-cell
     data-theme="safe"
     data-cols="2">
  <dual-col>狀態</dual-col>
  <dual-col>✅ 正常運作</dual-col>
  <dual-col>上次更新</dual-col>
  <dual-col>2025-06-01 08:30</dual-col>
</div>

主題色系

透過 theme: '名稱'（JS）或 theme="名稱"（HTML）套用。也可個別覆寫任何顏色選項。

主題一覽（點擊預覽各主題樣式） 
new DualCell('el', { theme: 'lavender' });

// 可用主題名稱：
// lavender  special  warning  sky     safe
// salmon    pink     orange   yellow  info
// stone     vanilla  indigo   focus
// shell     brown    default  attention

欄位設定

cols / colWidths — 欄數與比例

預設 2 欄。colWidths 用冒號分隔的數字設定每欄寬度比例（flex 值）。

3 欄，比例 1:2:1 
<div id="t-cols">
  <dual-col>標籤</dual-col>
  <dual-col>內容（佔2份）</dual-col>
  <dual-col>備注</dual-col>
  <dual-col>姓名</dual-col>
  <dual-col>Alice Wang（資深工程師）</dual-col>
  <dual-col>在職</dual-col>
</div>

new DualCell('t-cols', {
  theme: 'stone',
  cols: 3,
  colWidths: '1:2:1',
});

per-row col-widths / 固定 width

逐列設定欄寬 / 固定像素寬度 
<div id="t-w">
  <!-- 此列覆寫比例為 1:3 -->
  <dual-row col-widths="1:3">
    <dual-col>窄欄</dual-col>
    <dual-col>寬欄（佔三份）</dual-col>
  </dual-row>
  <!-- 固定寬度欄 -->
  <dual-row>
    <dual-col width="80px">80px</dual-col>
    <dual-col>剩餘空間</dual-col>
  </dual-row>
  <!-- span="all" 跨全欄 -->
  <dual-row>
    <dual-col span="all">跨全欄內容（span all）</dual-col>
  </dual-row>
</div>

new DualCell('t-w', { theme: 'indigo' });

選單按鈕（menu-action）

每個 <dual-col> 預設顯示選單按鈕。設定 menu-action 屬性決定行為，或 show-menu="false" 隱藏。

push / pull — 推送與拉取 
<div id="src">
  <dual-col menu-action="push">這段文字可推送</dual-col>
  <dual-col menu-action="pull">點 ⊙ 從目標拉取</dual-col>
</div>
<div id="tgt" style="margin-top:8px;padding:8px;border:1px dashed #555">
  目標區域（push 會寫入這裡）
</div>

new DualCell('src', {
  theme: 'special',
  targetId: 'tgt',
  menuButtonIconPush: 'bi-box-arrow-up-right',
  menuButtonIconPull: 'bi-box-arrow-in-down-left',
});
copy / swap / clear 
<div id="t-misc">
  <dual-row>
    <dual-col menu-action="copy">點 ⊙ 複製文字</dual-col>
    <dual-col menu-action="swap">點 ⊙ 與左欄互換</dual-col>
  </dual-row>
  <dual-row>
    <dual-col menu-action="clear">點 ⊙ 清空此格</dual-col>
    <dual-col show-menu="false">無選單按鈕</dual-col>
  </dual-row>
</div>

new DualCell('t-misc', { theme: 'orange' });

群組（dual-group）

用 <dual-group title="..."> 包裹列，點擊標題列可展開/收合。支援右側說明文字、圖示與初始收合狀態。

群組（可展開/收合） 
<div id="t-grp">
  <dual-group title="💼 個人資料"
              title-right="3 筆">
    <dual-col>姓名</dual-col><dual-col>Alice Wang</dual-col>
    <dual-col>部門</dual-col><dual-col>產品設計</dual-col>
    <dual-col>年資</dual-col><dual-col>5 年</dual-col>
  </dual-group>

  <!-- collapsed="true" 初始收合 -->
  <dual-group title="🔒 薪資資料"
              collapsed="true"
              title-right="點擊展開">
    <dual-col>月薪</dual-col><dual-col>NT$ 85,000</dual-col>
  </dual-group>
</div>

new DualCell('t-grp', { theme: 'lavender' });

遮罩（overlay）

在格子上疊加點擊才能揭開的遮罩。支援雙層（兩次點擊）與 invert 模式（亮底色遮罩）。

單層遮罩 / 雙層遮罩 / Invert 遮罩 
<div id="t-ov">
  <!-- 單層遮罩 -->
  <dual-row>
    <dual-col>機密欄位</dual-col>
    <dual-col
      overlay-1-text="點擊解鎖"
      overlay-1-color="#F08080">
      NT$ 250,000（已揭開）
    </dual-col>
  </dual-row>
  <!-- 雙層遮罩（需點兩次）-->
  <dual-row>
    <dual-col>雙重防護</dual-col>
    <dual-col
      overlay-1-text="第一層：確認身份"
      overlay-2-text="第二層：再次確認">
      最終機密內容
    </dual-col>
  </dual-row>
  <!-- Invert 模式：亮底遮罩 -->
  <dual-row>
    <dual-col>Invert 模式</dual-col>
    <dual-col
      overlay-1-text="解除遮蓋"
      overlay-invert="true">
      反色揭開
    </dual-col>
  </dual-row>
</div>

new DualCell('t-ov', { theme: 'warning' });

垂直輪播（dual-item）

在 <dual-col> 內放兩個以上 <dual-item>，自動啟動垂直滾動輪播。底部顯示讀秒進度條（可關閉）。

垂直輪播（2000ms 間隔） 
<div id="t-car">
  <dual-row>
    <dual-col>今日重點</dual-col>
    <dual-col carousel-interval="2000">
      <dual-item>🚀 產品已上線</dual-item>
      <dual-item>📊 本月 NPS +12</dual-item>
      <dual-item>🎯 目標達成率 94%</dual-item>
    </dual-col>
  </dual-row>
  <dual-row>
    <dual-col>最新公告</dual-col>
    <dual-col
      carousel-interval="3000"
      carousel-indicator="false">
      <dual-item>週五 16:00 全員會議</dual-item>
      <dual-item>下週一無早會</dual-item>
    </dual-col>
  </dual-row>
</div>

new DualCell('t-car', {
  theme: 'sky',
  carouselIndicatorColor: '#0ABDC6',
});

隱藏列與展開（show-next / auto-reveal）

列可初始隱藏，透過選單動作或定時器逐步展開。兩種情境互相獨立。

show-next — 按鈕點擊展開下一列 
<div id="t-sn">
  <dual-row>
    <dual-col>步驟 1：填寫基本資料</dual-col>
    <dual-col menu-action="show-next">
      點 ⊙ 展開步驟 2
    </dual-col>
  </dual-row>
  <dual-row hidden>
    <dual-col>步驟 2：上傳證件</dual-col>
    <dual-col menu-action="show-next">
      點 ⊙ 展開步驟 3
    </dual-col>
  </dual-row>
  <dual-row hidden>
    <dual-col span="all">
      ✅ 步驟 3：完成申請
    </dual-col>
  </dual-row>
</div>

new DualCell('t-sn', { theme: 'focus' });
auto-reveal-interval — 全域定時自動展開 
<div id="t-ar">
  <dual-col>已載入</dual-col>
  <dual-col>立即顯示</dual-col>
  <dual-row hidden>
    <dual-col>第 1 筆</dual-col>
    <dual-col>1.5s 後顯示</dual-col>
  </dual-row>
  <dual-row hidden>
    <dual-col>第 2 筆</dual-col>
    <dual-col>3.0s 後顯示</dual-col>
  </dual-row>
  <dual-row hidden>
    <dual-col>第 3 筆</dual-col>
    <dual-col>4.5s 後顯示</dual-col>
  </dual-row>
</div>

new DualCell('t-ar', {
  theme: 'safe',
  autoRevealInterval: 1500,
});

Slot 展開區（dual-slot / toggle）

<dual-slot> 放在 <dual-row> 內；搭配 menu-action="toggle" 的格子點擊後滑出展開區。

點擊展開 Slot 詳情 
<div id="t-slot">
  <dual-row>
    <dual-col>訂單 #20250601</dual-col>
    <dual-col menu-action="toggle">
      點擊查看明細
    </dual-col>
    <dual-slot>
      <p style="padding:8px;color:#C6C7BD">
        商品：MacBook Air × 1<br>
        運費：免運<br>
        合計：NT$ 42,900
      </p>
    </dual-slot>
  </dual-row>
  <dual-row>
    <dual-col>訂單 #20250528</dual-col>
    <dual-col menu-action="toggle">
      點擊查看明細
    </dual-col>
    <dual-slot>
      <p style="padding:8px;color:#C6C7BD">
        商品：AirPods Pro × 2<br>
        合計：NT$ 9,800
      </p>
    </dual-slot>
  </dual-row>
</div>

new DualCell('t-slot', { theme: 'salmon' });

Hover 預覽（hover-source / hover-target）

滑鼠移入格子時，將另一個元素（hover-source）的內容複製到目標元素（hover-target）。

hover-source / hover-target 
<!-- 隱藏資料來源 -->
<div id="src-a" style="display:none">
  🍎 Alice：資深工程師，5年資歷
</div>
<div id="src-b" style="display:none">
  🍋 Bob：產品經理，3年資歷
</div>

<div id="t-hov">
  <dual-row>
    <dual-col
      hover-source="src-a"
      hover-target="hov-output">
      Alice（移入查看）
    </dual-col>
    <dual-col
      hover-source="src-b"
      hover-target="hov-output">
      Bob（移入查看）
    </dual-col>
  </dual-row>
</div>

<!-- Hover 輸出區 -->
<div id="hov-output"
     style="margin-top:8px;padding:10px;
            border:1px dashed #555;color:#C6C7BD">
  ← 滑鼠移入上方格子查看詳情
</div>

new DualCell('t-hov', { theme: 'pink' });
