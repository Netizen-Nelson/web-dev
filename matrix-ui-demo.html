8 · Attribute 速查

matrix-ui（根元素）
theme shell · vanilla · sky · lavender · teal · special · indigo · stone · orange · pink · salmon
border 外框線 e.g. "1px solid" "2px dashed" "none"
row-border 橫向行分隔線 e.g. "1px solid"
col-border 縱向欄分隔線 e.g. "1px dashed" 預設 none
header-border 標題列與內容的分隔線 預設 "2px solid"
footer-border 內容與頁尾的分隔線 預設 "2px solid"
row-label-width 最左欄寬度 預設 160px
col-width 資料欄固定寬度（不設則 auto）
icon-size icon 的 font-size 預設 1.1rem
font-size 整表字體大小 預設 inherit
label-position "below"（預設）或 "above"
accent-border 預設省略或 "true"：邊框沿用 accent 色；"false"：改用主題內建暗化備用色
matrix-cell（資料格）
semantic positive · negative · neutral · warning · star · info · thumb · blank
icon 任何 Bootstrap Icon class，覆寫 semantic 的 icon
color palette 名稱或任何 CSS color，覆寫 semantic 的顏色
label icon 旁顯示的小字（與 label-position 配合）
data-popover-* 直接由 bp-popnote.js 接管，不需額外設定
matrix-footer
label 最左欄文字
子元素可混用 matrix-col（文字）和 matrix-cell（圖示），位置對應欄位順序。
全域 API
MatrixUIConfig.addTheme('myTheme', { accent, headerBg, border })
MatrixUIConfig.addSemantic('myIcon', { icon: 'bi-gem', color: '#C3A5E5' })
